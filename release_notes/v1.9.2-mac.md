Live Translator v1.9.2 for **macOS** (Apple Silicon: M1, M2, M3, M4 and newer). Does not run on Intel Macs.
Same features as the Windows version v1.9.2. Portable: no Python or anything else to install.

## Cài đặt
1. Tải **LiveTranslator_v1.9.2_mac.zip** ở mục Assets bên dưới và giải nén → được file `LiveTranslator_v1.9.2_mac.dmg`.
2. Mở file `.dmg`, kéo **Live Translator** vào thư mục **Applications**.
3. Click đúp vào Live Translator để chạy.
4. Lần đầu, nếu macOS chặn (app chưa có chữ ký Apple): vào **System Settings → Privacy & Security → Open Anyway**. Nếu vẫn báo app bị hỏng, mở Terminal và chạy:
   ```
   xattr -dr com.apple.quarantine "/Applications/Live Translator.app"
   ```
5. Khi app hỏi quyền dùng **micro**, bấm **Allow**. (Nếu lỡ từ chối: System Settings → Privacy & Security → Microphone → bật Live Translator.)

Mô hình nhận diện giọng nói và công cụ đăng nhập Claude đã có sẵn trong app. Cài đặt và thư viện Learning được lưu ở `~/Library/Application Support/LiveTranslator`.

## Có gì mới so với v1.8.4
- **Dịch nhanh hơn**: cắt câu ở chỗ ngắt nghỉ ngắn, kết nối Claude được "làm nóng" trước câu đầu, bản dịch sửa lại thay thế một lần (không hiện "…").
- **Restore nhanh**: hàng nghìn dòng chỉ vài giây; không dừng giữa chừng khi có dòng chưa dịch.
- **Bài tập**: dùng prompt của sách, tự điền kết quả bước trước, hộp chọn / hộp nhập / điền chỗ `[cần điền]`, lưu câu trả lời, làm tiếp bài dang dở.
- **📋 List output files**: xem, mở, lưu bản sao, xoá (vào Thùng rác) các file app đã tạo.
- Dòng "đang xử lý" ở thanh trên cùng.
- Riêng cho Mac: giao diện sáng cả khi bật Dark Mode, vẫn cập nhật khi cửa sổ ở phía sau (tắt App Nap), báo rõ khi micro bị chặn quyền, thoát sạch (Cmd+Q), PDF tiếng Việt dùng phông Arial, ⌘K / ⌘L, ⌘V để dán chứng chỉ.

## Đã kiểm thử
Tự động trên macOS 15 (GitHub Actions), 40 mục: cài từ file .dmg và mở 60 giây, thoát bằng Quit không lỗi; nhận diện giọng nói 2 người (chữ cuối hiện sau ≤ 0,3 s), căn hàng EN/VI, cuộn, Key takeaways, khung Claude hai phía, Enter gửi, backup/restore (1.500 dòng < 1 s), Output Folder, Learning (tài liệu, chứng chỉ, clipboard, PDF tiếng Việt, List output files, các hộp thoại bài tập), cảnh báo micro.
Chưa kiểm thử trên máy Mac thật: micro thật, đăng nhập Claude qua trình duyệt, gõ tiếng Việt bằng bộ gõ.
