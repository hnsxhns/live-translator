Live Translator v1.9.9.1 for **macOS** (Apple Silicon: M1, M2, M3, M4 and newer). Does not run on Intel Macs.
Same features as the Windows version v1.9.9, plus a Mac fix. Portable: no Python or anything else to install.

## Cài đặt
1. Tải **LiveTranslator_v1.9.9.1_mac.zip** ở mục Assets bên dưới và giải nén → được file `LiveTranslator_v1.9.9.1_mac.dmg`.
2. Mở file `.dmg`, kéo **Live Translator** vào thư mục **Applications**.
3. Click đúp vào Live Translator để chạy.
4. Lần đầu, nếu macOS chặn (app chưa có chữ ký Apple): vào **System Settings → Privacy & Security → Open Anyway**. Nếu vẫn báo app bị hỏng, mở Terminal và chạy:
   ```
   xattr -dr com.apple.quarantine "/Applications/Live Translator.app"
   ```
5. Khi app hỏi quyền dùng **micro**, bấm **Allow**. (Nếu lỡ từ chối: System Settings → Privacy & Security → Microphone → bật Live Translator.)

Mô hình nhận diện giọng nói và công cụ đăng nhập Claude đã có sẵn trong app. Cài đặt, thư viện Learning, đăng nhập trang Source và mô hình chất lượng cao (nếu tải) được lưu ở `~/Library/Application Support/LiveTranslator`.

## Có gì mới so với v1.9.8
- **Source cho trang cần đăng nhập**: bấm Source mở một cửa sổ trình duyệt nhỏ; đăng nhập vào trang khoá học, mở trang chứa tài liệu (Materials) rồi bấm nút xanh **📥 Tải tài liệu mới từ trang này**. App tải các tài liệu mới bằng chính phiên đăng nhập đó và đưa lên cho Claude. Lần sau cửa sổ nhớ đăng nhập và trang tài liệu, tự quét sau vài giây rồi tự đóng.
- Chất lượng nghe **Cao** tự tắt khi máy Windows sắp hết bộ nhớ (trên Mac không cần).
- Riêng cho Mac: cửa sổ Source dùng WebKit của macOS; sửa lỗi cửa sổ không tự đóng sau khi quét (app đứng chờ).
