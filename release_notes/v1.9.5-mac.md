Live Translator v1.9.5 for **macOS** (Apple Silicon: M1, M2, M3, M4 and newer). Does not run on Intel Macs.
Same features as the Windows version v1.9.5. Portable: no Python or anything else to install.

## Cài đặt
1. Tải **LiveTranslator_v1.9.5_mac.zip** ở mục Assets bên dưới và giải nén → được file `LiveTranslator_v1.9.5_mac.dmg`.
2. Mở file `.dmg`, kéo **Live Translator** vào thư mục **Applications**.
3. Click đúp vào Live Translator để chạy.
4. Lần đầu, nếu macOS chặn (app chưa có chữ ký Apple): vào **System Settings → Privacy & Security → Open Anyway**. Nếu vẫn báo app bị hỏng, mở Terminal và chạy:
   ```
   xattr -dr com.apple.quarantine "/Applications/Live Translator.app"
   ```
5. Khi app hỏi quyền dùng **micro**, bấm **Allow**. (Nếu lỡ từ chối: System Settings → Privacy & Security → Microphone → bật Live Translator.)

Mô hình nhận diện giọng nói và công cụ đăng nhập Claude đã có sẵn trong app. Cài đặt và thư viện Learning được lưu ở `~/Library/Application Support/LiveTranslator`.

## Có gì mới so với v1.9.2
- **Nghe tiếng Anh chính xác hơn**: không cắt câu ở chỗ ngập ngừng ngắn (câu không còn bị vỡ), Whisper đọc kỹ hơn (beam 5) và được báo trước các thuật ngữ của khoá học, bỏ các câu Whisper tự bịa ("thank you for watching"...). Trên Windows đo được lỗi từ giảm từ 1,8% xuống 0,6% với âm thanh lớp học có tiếng ồn.
- Chỉ dịch lại khi chữ thật sự thay đổi; bản dịch mới thay tại chỗ.
- **Learning → Source**: lưu link trang web chứa tài liệu; mỗi lần bấm, app quét trang, tự tải các tài liệu mới vào thư mục học và đưa lên cho Claude.
- Riêng cho Mac: tải HTTPS của Source dùng chứng chỉ có sẵn trong app (Python trên macOS không dùng kho chứng chỉ của hệ thống).

## Đã kiểm thử
Tự động trên macOS 15 (GitHub Actions), 44 mục: cài từ file .dmg và mở 60 giây, thoát bằng Quit không lỗi; nhận diện giọng nói 2 người (chữ đầu ~0,9 s, chữ cuối hiện sau ≤ 0,45 s), căn hàng EN/VI, cuộn, Key takeaways, khung Claude hai phía, Enter gửi, backup/restore (1.500 dòng < 1 s), Output Folder, Learning (tài liệu, chứng chỉ, clipboard, PDF tiếng Việt, List output files, hộp thoại bài tập, Source: quét trang + tải tài liệu mới + tải HTTPS), cảnh báo micro.
Chưa kiểm thử trên máy Mac thật: micro thật, đăng nhập Claude qua trình duyệt, gõ tiếng Việt bằng bộ gõ.
